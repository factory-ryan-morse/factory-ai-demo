About Factory

Who we are

Factory builds software development agents called Droids. They run in the places your team already works, including the IDE, the terminal, CI/CD, and Slack, and they take on complete engineering tasks rather than autocompleting lines of code.

The result is autonomy across the software delivery lifecycle: engineers define intent, Droids handle execution. Factory is model-agnostic, tool-agnostic, and built for enterprise use with SOC 2, GDPR, and ISO 42001 coverage.

Agenda

What we will cover

Three parts, each demonstrated live in a real repository rather than on slides.

01

Orchestration

How a large, multi-feature project gets planned, scoped, and executed by a coordinated team of agents.

Missions

Describe a large project in plain language, collaborate on the plan, then let Droid break it into milestones and run parallel workers until it ships.

02

Measurement

The two surfaces that tell you whether your codebase is ready for agents, and what you get back once it is.

Agent readiness

A scored assessment of how well your codebase supports autonomous development across eight pillars and five maturity levels, with a report on what to fix first.

Agent effectiveness

Connects agent spend to the work it actually produced, so you can see how much faster your organization ships and where the return is coming from.

03

SDLC automations

Standing automations that run on your repositories without anyone opening a session.

Code review

Every pull request gets reviewed automatically in CI, with comments on real correctness and design problems instead of style nits.

Security review

Security-focused reviews of pull requests and full-codebase audits, using STRIDE, OWASP, and supply-chain methodology.

Incident response

Production alerts land in Slack, and Droid investigates root cause, then either resolves the incident or hands your on-call a written diagnosis.

AutoWiki

Generates a structured, searchable wiki for any repository and refreshes it automatically on every push to the default branch.
